# AI Usage Disclosure and Attribution

## How AI was used

I used **OpenAI ChatGPT/Codex** throughout the development of AIOpsDesk. It helped me understand the project, work through the steps and build different parts of the application. Its help included writing code and documents, explaining commands, finding problems and suggesting fixes.

### Planning and learning

AI helped divide the project into smaller steps and explain the purpose of each step. I asked questions about the tools, how the parts of the application connect and why a particular method was being used. I directed the work toward a small project with simple methods so that I could run the steps and understand them.

### Writing code and commands

AI helped write and revise Python scripts, frontend code, settings and terminal commands. This included parts of the prediction service, login system, feedback workflow, training pipeline and monitoring setup. Some of the code in the final project was generated by AI and then changed as the project developed.

For much of the development, I ran the suggested commands in my terminal and shared the output. When local file access was available, the assistant also created or edited files and ran checks directly.

### Finding and fixing problems

When a command failed or the application did not behave as expected, I shared the output with AI. It helped explain the error and suggest changes. I ran commands and checked the application as we worked through issues with model serving, containers, ports, connections and other parts of the project.

### Testing the work

AI helped write tests and checks for the application. It also helped compare outputs, check saved models and test whether project files could be restored. I supplied results from the commands I ran and used the application to try its workflows. The assistant ran some checks directly when it had access to the project.

### Writing documents and preparing the repository

AI helped draft and improve the README, project report, design documents and user instructions. It also helped create the flowchart, format the PDF files and suggest useful screenshots. I captured the screenshots and requested changes to the wording, appearance and contents of the documents.

AI also helped review the repository, remove files that were not needed and prepare the steps for restoring the project after cloning it.

## My part in the project

I chose how simple the project should be, asked for explanations and guided changes during development. I ran development commands, shared their output, tried the application screens and captured screenshots of the work. I also managed the Git commits and pushed the project to GitHub.

The project was built through these steps together with AI assistance. I do not claim that I wrote every line of code or every part of the documentation without help.

## Attribution and responsibility

I acknowledge **OpenAI ChatGPT/Codex** for its help with planning, explanations, code, problem solving, testing and writing.

AI helped produce parts of the submitted work, rather than only correcting spelling or giving general advice. I remain responsible for the work I submit, making sure its claims match what was done and explaining how the project works.
