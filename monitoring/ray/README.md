# Ray monitoring connection

The setup helper copies dashboards generated by the installed Ray version and writes its current metric targets here. Those files are local runtime output and stay out of Git.

Start Ray using `bash scripts/start_ray_dashboard.sh`. Grafana serves Ray panels from port 3001; Prometheus discovers the current metric endpoints. Existing AIOpsDesk dashboards and authentication are retained.

After stopping Ray, run `python scripts/configure_ray_monitoring.py --clear` to remove its temporary scrape targets.
